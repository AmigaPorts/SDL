# F / / Interval Timers (Timer A, Timer B) / PB on/off


A control bit (CRx1) allows the timer output to appear on a  [port B](../Hardware_Manual_guide/node0131.html) 
output line (PB6 for timer A and PB7 for timer B).  This function
overrides the  [DDRB](../Hardware_Manual_guide/node0131.html)  control bit and forces the appropriate PB line to
become an output.
