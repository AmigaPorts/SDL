# 8 Interface Hardware / The Keyboard


The keyboard is interfaced to the system via the serial  [shift register](../Hardware_Manual_guide/node013E.html) 
on one of the 8520 CIA chips.  The keyboard data line (KDAT) is connected
to the  [SP pin](../Hardware_Manual_guide/node0117.html) , the keyboard clock (KCLK) is connected to the  [CNT pin](../Hardware_Manual_guide/node0117.html) .
 [Appendix G](../Hardware_Manual_guide/node0172.html)  contains a full description of the interface.
