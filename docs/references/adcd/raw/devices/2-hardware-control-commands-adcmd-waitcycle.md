# 2 / Hardware Control Commands / ADCMD_WAITCYCLE


This is a single-channel command. [ADCMD_WAITCYCLE](../Includes_and_Autodocs_2._guide/node04AC.html) is replied to when the
current cycle has completed.  If there is no [CMD_WRITE](../Devices_Manual_guide/node0033.html) in progress, it
returns immediately.
