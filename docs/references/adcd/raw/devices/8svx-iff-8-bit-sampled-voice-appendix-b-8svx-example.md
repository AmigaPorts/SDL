# 8SVX IFF 8-Bit Sampled Voice / Appendix B. 8SVX Example


Here's a box diagram for a simple example containing the three octave [BODY](../Devices_Manual_guide/node02D0.html)
shown earlier in Figure 2.


```c
                  +--------------------------+
                  |                          |
                  |  'FORM'            362   |  FORM 362 8SVX
                  |                          |
               -  +--------------------------+
               |  |                          |
               |  |    '8SVX'                |
               |  |                          |
               |  |  +--------------------+  |
               |  |  |  'VHDR'       20   |  |  .VHDR 20
               |  |  |--------------------|  |
               |  |  |  24, 16, 8, 10000, |  |
               |  |  |  3, 0, 1.0         |  |
               |  |  +--------------------+  |
               |  |                          |
               |  |  +--------------------+  |
               |  |  |  'NAME'       11   |  |  .NAME 11
               |  |  |--------------------|  |
               |  |  |  'bass guitar'     |  |
          368 <   |  +--------------------+  |
         bytes |  |     0                    |
               |  |  +--------------------+  |
               |  |  |  '(c) '        20  |  |
               |  |  |--------------------|  |  .(c)  20
               |  |  |'1985 Electronic    |  |
               |  |  | Arts'              |  |
               |  |  +--------------------+  |
               |  |                          |
               |  |  +--------------------+  |
               |  |  |  'BODY'      280   |  |
               |  |  |--------------------|  |  .BODY 280
               |  |  |  1, 2, 3, 4....    |  |
               |  |  +--------------------+  |
               |  |                          |
               -- +--------------------------+
```
The "0" after the NAME chunk is a pad byte.
