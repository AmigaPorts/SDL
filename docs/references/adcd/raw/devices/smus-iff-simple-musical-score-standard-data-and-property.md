# SMUS IFF Simple Musical Score / Standard Data and Property Chunks


A FORM [SMUS](../Devices_Manual_guide/node02AB.html) contains a required property "[SHDR](../Devices_Manual_guide/node02B3.html)" followed by any number of
parallel "track" data chunks "[TRAK](../Devices_Manual_guide/node02B7.html)".  Optional property chunks such as
"NAME", copyright "(c) ", and instrument reference "INS1" may also appear.
Any of the properties may be shared over a [LIST](../Devices_Manual_guide/node01CA.html#line49) of FORMs [SMUS](../Devices_Manual_guide/node02AB.html) by putting
them in a [PROP](../Devices_Manual_guide/node01CA.html#line49) [SMUS](../Devices_Manual_guide/node02AB.html).  [See the IFF reference.]
