# Standard Data and Property Chunks / End-Mark SEvent


The [SEvent](../Devices_Manual_guide/node02B7.html#line29) type SID_Mark is reserved for an end marker in working memory.
This event is never stored in a file.  It may be useful if you decide to
use the filed [TRAK](../Devices_Manual_guide/node02B7.html) format intact in working memory.
