# 2 / Audio And System I/O Functions / AbortIO()


This function can be used to cancel requests for [ADCMD_ALLOCATE](../Includes_and_Autodocs_2._guide/node04A6.html),
[ADCMD_LOCK](../Includes_and_Autodocs_2._guide/node04A9.html), [CMD_WRITE](../Includes_and_Autodocs_2._guide/node04B6.html), or [ADCMD_WAITCYCLE](../Includes_and_Autodocs_2._guide/node04AC.html). When used with the audio
device, [AbortIO()](../Includes_and_Autodocs_2._guide/node04A5.html) always succeeds.
