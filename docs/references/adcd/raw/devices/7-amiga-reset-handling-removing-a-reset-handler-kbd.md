# 7 / Amiga Reset Handling / Removing A Reset Handler (KBD_REMRESETHANDLER)


This command is used to remove a keyboard reset handler from the system.
You need to supply the same [Interrupt](../Includes_and_Autodocs_2._guide/node008C.html#line23) structure to this command that you
used with the [KBD_ADDRESETHANDLER](../Includes_and_Autodocs_2._guide/node050D.html) command.
