# Standard Data and Property Chunks / Set MIDI Preset SEvent


The [SEvent](../Devices_Manual_guide/node02B7.html#line29) SID_MIDI_Preset is for recorder programs to record the
set-MIDI-preset low level event.  The data byte contains a MIDI preset
number. Other programs should use [instrument registers](../Devices_Manual_guide/node02B0.html) instead.
