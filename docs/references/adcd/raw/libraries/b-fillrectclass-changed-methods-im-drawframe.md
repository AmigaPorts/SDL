# B / fillrectclass / Changed Methods: IM_DRAWFRAME


This method asks a [fillrectclass](../Libraries_Manual_guide/node04EB.html) object to render itself relative to the
position in its embedded [Image](../Libraries_Manual_guide/node01BA.html) structure, but using the width and height
passed in the message's Dimensions.Width and Dimensions.Height fields.
See the [imageclass](../Libraries_Manual_guide/node04D1.html) description of [IM_DRAWFRAME](../Libraries_Manual_guide/node04D5.html) for more details.
