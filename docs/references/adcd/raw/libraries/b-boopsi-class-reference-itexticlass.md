# B Boopsi Class Reference / itexticlass


Class:                  itexticlass
Superclass:             [imageclass](../Libraries_Manual_guide/node04D1.html)
Include File:           <intuition/[imageclass.h](../Includes_and_Autodocs_2._guide/node00E3.html)>

This is a class of image objects that render an [IntuiText](../Libraries_Manual_guide/node01C7.html) structure.
Using some of the [imageclass](../Libraries_Manual_guide/node04D1.html) attributes, the object can override some of
the parameters in the IntuiText structure.  This class makes it easy to
share an IntuiText structure between objects.
