# C Sample Library Source Code


This appendix contains the source code to an Exec library called
sample.library.  It also includes some example code that uses the library.
The files include:

 [makefile](../Libraries_Manual_guide/node0603.html)            A make file to build the library and examples.
 [asmsupp.i](../Libraries_Manual_guide/node0604.html)           Assorted low level assembly support routines used by
                     the example library.
 [sample_rev.i](../Libraries_Manual_guide/node0605.html)        The version file generated by bumprev.
 [sample_protos.h](../Libraries_Manual_guide/node0606.html)     Prototypes for sample.library functions.
 [sample_pragmas.h](../Libraries_Manual_guide/node0607.html)    Pragmas for sample.library functions.
 [samplebase.i](../Libraries_Manual_guide/node0608.html)        Definition of sample.library base.
 [samplebase.h](../Libraries_Manual_guide/node0609.html)        include file defining sample.library base.
 [sample.library.asm](../Libraries_Manual_guide/node058C.html)  Example run-time library source code.
 [sample_lvos.asm](../Libraries_Manual_guide/node060A.html)     The .fd file for the sample library.
 [sample_stubs.asm](../Libraries_Manual_guide/node060B.html)    Assembler stubs for C interface to library functions.
 [clibtest.c](../Libraries_Manual_guide/node060C.html)          C example that calls the sample.library functions.
 [alibtest.asm](../Libraries_Manual_guide/node060D.html)        Assembly code example that calls the sample.library

                     functions.
