# 5 / Gadget Imagery / Gadget Text


Gadgets may include text information in the form of a linked list of
[IntuiText](../Libraries_Manual_guide/node01C7.html) structures.  A pointer to the first IntuiText structure in the
list is placed in the [Gadget](../Libraries_Manual_guide/node0149.html) structure's [GadgetText](../Libraries_Manual_guide/node0149.html#line111) field.  The text is
positioned relative to the top left corner of the gadget's select box.
For more information on IntuiText, see the
"[Intuition Images, Line Drawing and Text](../Libraries_Manual_guide/node01C6.html)" chapter.
