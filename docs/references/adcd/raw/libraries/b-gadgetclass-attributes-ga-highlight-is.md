# B / gadgetclass / Attributes: GA_Highlight (IS)


This attribute corresponds to the [GFLG_GADGHIGHBITS](../Includes_and_Autodocs_2._guide/node00D4.html#line264) portion of the
gadget's [Gadget.Flags](../Libraries_Manual_guide/node0149.html#line48) field.  This attribute can be one of four values
(from <intuition/[intuition.h](../Includes_and_Autodocs_2._guide/node00D4.html#line264)>):


```c
    [GFLG_GADGHCOMP](../Libraries_Manual_guide/node014A.html#line8), [GFLG_GADGHBOX](../Libraries_Manual_guide/node014A.html#line12), [GFLG_GADGHIMAGE](../Libraries_Manual_guide/node014A.html#line16), [GFLG_GADGHNONE](../Libraries_Manual_guide/node014A.html#line5)
```
See the "[Intuition Gadgets](../Libraries_Manual_guide/node014A.html)" chapter of the Amiga ROM Kernel Reference
Manual: Libraries for more information.
