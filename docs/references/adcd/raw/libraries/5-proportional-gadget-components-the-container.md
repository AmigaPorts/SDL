# 5 / / Proportional Gadget Components / The Container


The container is the area in which the [knob](../Libraries_Manual_guide/node015A.html) can move.  It is actually the
select box of the gadget.  The size of the container, like that of any
other gadget select box, can be relative to the size of the window.  The
position of the container can be relative to any of the Intuition window's
border.

Clicking in the container around the [knob](../Libraries_Manual_guide/node015A.html) will increment or decrement the
value of the gadget (the [pot variables](../Libraries_Manual_guide/node015B.html)) by the appropriate amount
(specified in the [body variables](../Libraries_Manual_guide/node015C.html)).  The knob will move towards the point
clicked when action is taken.
