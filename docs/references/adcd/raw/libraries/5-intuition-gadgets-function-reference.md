# 5 Intuition Gadgets / Function Reference


The following are brief descriptions of the Intuition functions that
relate to the use of Intuition gadgets. See the Amiga ROM Kernel Reference
Manual: Includes and Autodocs for details on each function call.


               Table 5-3: Functions for Intuition Gadgets
  _______________________________________________________________________
 |                                                                       |
 |      Function                      Description                        |
 |=======================================================================|
 |       [AddGadget()](../Includes_and_Autodocs_2._guide/node01FC.html)  Add a gadget to an open window or requester.       |
 |        [AddGList()](../Includes_and_Autodocs_2._guide/node01FD.html)  Add some gadgets to an open window or requester.   |
 |    [RemoveGadget()](../Includes_and_Autodocs_2._guide/node0246.html)  Remove a gadget from an open window or requester.  |
 |     [RemoveGList()](../Includes_and_Autodocs_2._guide/node0247.html)  Remove some gadgets from an open window or         |
 |                    requester.                                         |
 |  [RefreshGadgets()](../Includes_and_Autodocs_2._guide/node0240.html)  Refresh all gadgets for the window or requester.   |
 |    [RefreshGList()](../Includes_and_Autodocs_2._guide/node0241.html)  Refresh some gadgets from the window or requester. |
 |-----------------------------------------------------------------------|
 |      [ModifyProp()](../Includes_and_Autodocs_2._guide/node022A.html)  Change the values of an open [proportional](../Libraries_Manual_guide/node0153.html) gadget.  |
 |   [NewModifyProp()](../Includes_and_Autodocs_2._guide/node022E.html)  Optimized version of ModifyProp().                 |
 |-----------------------------------------------------------------------|
 |        [OnGadget()](../Includes_and_Autodocs_2._guide/node0235.html)  Enable an open gadget.                             |
 |       [OffGadget()](../Includes_and_Autodocs_2._guide/node0233.html)  Disable an open gadget.                            |
 |-----------------------------------------------------------------------|
 |  [ActivateGadget()](../Includes_and_Autodocs_2._guide/node01F9.html)  Activate an open [string](../Libraries_Manual_guide/node0164.html) gadget.                    |
 |     [SetEditHook()](../Includes_and_Autodocs_2._guide/node0251.html)  Change the global edit hook for string gadgets.    |
