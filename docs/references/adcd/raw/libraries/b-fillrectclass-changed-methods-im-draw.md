# B / fillrectclass / Changed Methods: IM_DRAW


This method asks a [fillrectclass](../Libraries_Manual_guide/node04EB.html) object to render itself relative to the
position ([LeftEdge and TopEdge](../Libraries_Manual_guide/node01BA.html#line17)) and dimensions ([Width and Height](../Libraries_Manual_guide/node01BA.html#line32)) in its
embedded [Image](../Libraries_Manual_guide/node01BA.html) structure.  See the [imageclass](../Libraries_Manual_guide/node04D1.html) description of [IM_DRAW](../Libraries_Manual_guide/node04D2.html) for
more details.
