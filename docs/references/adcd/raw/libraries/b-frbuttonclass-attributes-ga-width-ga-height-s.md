# B / frbuttonclass / Attributes: GA_Width, GA_Height (S)


These attribute correspond to the gadget's Width and Height fields.  If
the framing image supports [IM_FRAMEBOX](../Libraries_Manual_guide/node04D8.html), changing these resizes the framing
image.  The framing image re-centers itself around the display element as
best it can, and the [frbuttonclass](../Libraries_Manual_guide/node0524.html) gadget re-renders the whole itself.
