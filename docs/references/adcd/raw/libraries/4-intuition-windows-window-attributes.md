# 4 Intuition Windows / Window Attributes


This section discusses all window attributes.  As mentioned earlier, a
window's attributes may be specified with either [TagItems](../Libraries_Manual_guide/node0102.html#line8), [NewWindow](../Libraries_Manual_guide/node0102.html#line8) or
[ExtNewWindow](../Libraries_Manual_guide/node0102.html#line8) depending on how the window is opened.

Attributes are listed here by their [TagItem](../Libraries_Manual_guide/node0102.html#line8) ID name (TagItem.ti_Tag).  For
each tag item, the equivalent field setting in the [NewWindow](../Libraries_Manual_guide/node0102.html#line8) structure is
also listed if it exists.  Some window attributes specified with tags are
available only in Release 2 and have no NewWindow equivalent.
