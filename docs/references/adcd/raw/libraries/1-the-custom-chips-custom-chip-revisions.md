# 1 / / The Custom Chips / Custom Chip Revisions


The [custom chips](../Libraries_Manual_guide/node0016.html) have been revised as the Amiga platform has evolved and
newer models of the Amiga developed.  The latest revision of the Amiga
custom chips is known as the Enhanced Chip Set, or [ECS](../Libraries_Manual_guide/node0319.html).  Certain features
of the Amiga operating system, such as higher resolution screens and
[special genlock modes](../Libraries_Manual_guide/node036C.html), require the ECS version of the custom chips.  In
this book, features that require ECS are noted in the accompanying text.
For more details about the special features of ECS, see [Appendix C](../Hardware_Manual_guide/node0099.html) of
the Amiga Hardware Reference Manual.
