# B / imageclass / Attributes: IA_Pens ()


This attribute points to an alternative pen array for the image.
[Imageclass](../Libraries_Manual_guide/node04D1.html) does not support this attribute, it is described here for
subclasses to use.  See the "[Intuition Screens](../Libraries_Manual_guide/node00EB.html)" chapter of the Amiga ROM
Kernel Reference Manual: Libraries for more information on the pen array.
