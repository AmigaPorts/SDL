# 26 Exec Interrupts / Function Reference


The following chart gives a brief description of the Exec functions that
control interrupts.  See the Amiga ROM Kernel Reference Manual: Includes
and Autodocs for details about each call.


                   Table 26-2: Exec Interrupt Functions
  ________________________________________________________________________
 |                                                                        |
 | Interrupt Function                Description                          |
 |========================================================================|
 |  [AddIntServer()](../Includes_and_Autodocs_2._guide/node0326.html)  Add an interrupt server to a system server chain.     |
 |         [Cause()](../Includes_and_Autodocs_2._guide/node033D.html)  Cause a software interrupt.                           |
 |       [Disable()](../Includes_and_Autodocs_2._guide/node034A.html)  Disable interrupt processing.                         |
 |        [Enable()](../Includes_and_Autodocs_2._guide/node034C.html)  Restart system interrupt processing.                  |
 |  [RemIntServer()](../Includes_and_Autodocs_2._guide/node0371.html)  Remove an interrupt server from a system server chain.|
 |  [SetIntVector()](../Includes_and_Autodocs_2._guide/node037D.html)  Set a new handler for a system interrupt vector.      |
 |________________________________________________________________________|
