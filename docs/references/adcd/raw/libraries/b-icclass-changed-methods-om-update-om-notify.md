# B / icclass / Changed Methods: OM_UPDATE/OM_NOTIFY


These methods tell the object to notify its [ICA_TARGET](../Libraries_Manual_guide/node04C9.html) of attribute
changes by sending the target an OM_UPDATE message.  If the object has an
[ICA_MAP](../Libraries_Manual_guide/node04CA.html), it maps the attribute IDs it finds to new attribute IDs.  See the
[rootclass](../Libraries_Manual_guide/node04BB.html) descriptions of [OM_NOTIFY](../Libraries_Manual_guide/node04C5.html) and [OM_UPDATE](../Libraries_Manual_guide/node04C4.html) for more information.
The return value for this method is not explicitly defined.
