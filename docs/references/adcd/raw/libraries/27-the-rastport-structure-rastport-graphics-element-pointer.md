# 27 / / The RastPort Structure / RastPort Graphics Element Pointer


The graphics element pointer in the [RastPort](../Libraries_Manual_guide/node034A.html) structure is called [GelsInfo](../Libraries_Manual_guide/node0377.html#line6).
If you are doing graphics animation using the GELS system, this pointer
must refer to a properly initialized GelsInfo structure.  See the chapter
on "[Graphics Sprites, Bobs and Animation](../Libraries_Manual_guide/node0377.html)" for more information.
