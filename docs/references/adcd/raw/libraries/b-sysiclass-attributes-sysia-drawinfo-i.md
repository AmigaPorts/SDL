# B / sysiclass / Attributes: SYSIA_DrawInfo (I)


This attribute contains a pointer to a [DrawInfo](../Libraries_Manual_guide/node00DE.html#line6) structure (defined in
<intuition/[screens.h](../Includes_and_Autodocs_2._guide/node00DD.html#line46)>) describing the target screen.  The class requires
this attribute in order to generate the image into a bitmap cache.
