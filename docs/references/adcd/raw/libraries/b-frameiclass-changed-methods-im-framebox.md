# B / frameiclass / Changed Methods: IM_FRAMEBOX


This method asks a [frameiclass](../Libraries_Manual_guide/node04DF.html) image what its dimensions would be if it
has to frame a specific rectangular area.  See the [imageclass](../Libraries_Manual_guide/node04D1.html) description
for [IM_FRAMEBOX](../Libraries_Manual_guide/node04D8.html) for more information.
