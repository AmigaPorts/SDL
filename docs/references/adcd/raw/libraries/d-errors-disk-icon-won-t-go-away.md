# D / Errors / Disk Icon Won't Go Away


This occurs when a program leaves a [Lock()](../Includes_and_Autodocs_2._guide/node02C6.html) on one or more of a disk's
files or directories.  A memory loss of exactly 24 bytes is usually Lock()
which has not been [UnLock()](../Includes_and_Autodocs_2._guide/node0307.html)ed.
