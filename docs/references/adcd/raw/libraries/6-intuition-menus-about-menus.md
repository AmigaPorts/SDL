# 6 Intuition Menus / About Menus


Intuition's menu system provides applications with a convenient way to
group together and display the commands and options available to the user.
In most cases menus consist of a fixed list of text choices however this
is not a requirement.  Items in the menu list may be either graphic images
or text, and the two types can be freely used together.  The number of
items in a menu can be changed if necessary.
