# 6 / Setting Up Menus / Toggle Selection


Some of the checkmarked menu items may be of the toggle select type.  Each
time the user accesses such an item, it changes state, selected or
unselected.  To make an attribute item toggle select, set both the [CHECKIT](../Libraries_Manual_guide/node019B.html#line3)
and the [MENUTOGGLE](../Libraries_Manual_guide/node019B.html#line24) flags for that menu item.  Of course, the [CHECKED](../Libraries_Manual_guide/node019B.html#line7) flag
may be preset to the desired initial state.
