# B / groupgclass / Attributes: GA_Left, GA_Top (IS)


These attributes correspond to the embedded [Gadget.LeftEdge](../Libraries_Manual_guide/node0149.html#line33) and
[Gadget.TopEdge](../Libraries_Manual_guide/node0149.html#line33) fields.  Setting these attributes in [groupgclass](../Libraries_Manual_guide/node052B.html) object
causes it to change its position as well as the position of each of the
gadgets that have been added to the group gadget.
