# B / gadgetclass / Attributes: GA_SysGType (IS)


This attribute corresponds to the system gadget type portion of the
gadget's [Gadget.GadgetType](../Libraries_Manual_guide/node0149.html#line58) fields.  This attribute is any one of the
following flags (from <intuition/[intuition.h](../Includes_and_Autodocs_2._guide/node00D4.html#line392)>):


    GTYP_SIZING, GTYP_WDRAGGING, GTYP_SDRAGGING, GTYP_WUPFRONT,
    GTYP_SUPFRONT, GTYP_WDOWNBACK, GTYP_SDOWNBACK, GTYP_CLOSE
See the "[Intuition Gadgets](../Libraries_Manual_guide/node0149.html#line58)" chapter of the Amiga ROM Kernel Reference
Manual: Libraries for more information.
