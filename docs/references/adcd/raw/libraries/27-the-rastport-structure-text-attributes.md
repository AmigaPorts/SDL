# 27 / / The RastPort Structure / Text Attributes


Text attributes and font information are stored in the [RastPort](../Libraries_Manual_guide/node034A.html) fields
[Font](../Libraries_Manual_guide/node034A.html#line27), [AlgoStyle](../Libraries_Manual_guide/node034A.html#line27), [TxFlags](../Libraries_Manual_guide/node034A.html#line27), [TxHeight](../Libraries_Manual_guide/node034A.html#line27), [TxWidth](../Libraries_Manual_guide/node034A.html#line27), [TxBaseline](../Libraries_Manual_guide/node034A.html#line27) and [TxSpacing](../Libraries_Manual_guide/node034A.html#line27).
These are normally set by calls to the graphics font routines which are
covered separately in the chapter on "[Graphics Library and Text](../Libraries_Manual_guide/node03D2.html)".
