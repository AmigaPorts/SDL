# B / propgclass / Attributes: PGA_Freedom (IG)


This attribute tells a [propgclass](../Libraries_Manual_guide/node0507.html) object on which axis the gadget's knob
is free to move, the horizontal or the vertical.  It is either [FREEHORIZ](../Libraries_Manual_guide/node0161.html#line27)
or [FREEVERT](../Libraries_Manual_guide/node0161.html#line27).  The default is FREEVERT.
