# B Boopsi Class Reference / modelclass


Class:                  modelclass
Superclass:             [icclass](../Libraries_Manual_guide/node04C6.html)
Include File:           <intuition/[icclass.h](../Includes_and_Autodocs_2._guide/node00DB.html)>

A class of OM_UPDATE forwarding objects that have multiple targets.  In
addition to the features the modelclass object inherits from [icclass](../Libraries_Manual_guide/node04C6.html), when
a modelclass object gets an [OM_UPDATE](../Libraries_Manual_guide/node04C4.html) message, it forwards that [OM_UPDATE](../Libraries_Manual_guide/node04D0.html)
message to all of the objects in its broadcast list.
