# B / buttongclass / Changed Methods: GM_RENDER


All rendering is passed along to the [GadgetRender.Image](../Libraries_Manual_guide/node0149.html#line91) (the [GA_Image](../Libraries_Manual_guide/node0523.html)
attribute).  This method can tell its image to render in any of four image
states: [IDS_INACTIVESELECTED](../Libraries_Manual_guide/node04D2.html#line39), [IDS_INACTIVENORMAL](../Libraries_Manual_guide/node04D2.html#line35), [IDS_SELECTED](../Libraries_Manual_guide/node04D2.html#line26), or
[IDS_NORMAL](../Libraries_Manual_guide/node04D2.html#line23).
