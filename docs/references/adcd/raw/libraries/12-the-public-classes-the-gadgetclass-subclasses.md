# 12 / / The Public Classes / The Gadgetclass Subclasses


Like [imageclass](../Libraries_Manual_guide/node0209.html), applications do not normally create objects of
[gadgetclass](../Libraries_Manual_guide/node04F2.html), but instead create objects of its subclasses. Currently,
gadgetclass has four subclasses:

[propgclass](../Libraries_Manual_guide/node0507.html)

    An easy to implement, horizontal or vertical proportional gadget.
[strgclass](../Libraries_Manual_guide/node0510.html)

    A string gadget.
[groupgclass](../Libraries_Manual_guide/node052B.html)

    A special gadget class that creates one composite gadget out of
    several others.
[buttongclass](../Libraries_Manual_guide/node051F.html)

    A button gadget that keeps sending button presses while the user
    holds it down.
buttongclass has a subclass of its own:

[frbuttonclass](../Libraries_Manual_guide/node0524.html)

    A buttongclass gadget that outlines its imagery with a frame.
For specific information on these classes, see the Boopsi Class Reference
in the [Appendix B](../Libraries_Manual_guide/node04B9.html) of this manual.
