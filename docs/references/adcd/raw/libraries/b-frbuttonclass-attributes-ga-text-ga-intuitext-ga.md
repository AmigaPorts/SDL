# B / frbuttonclass / Attributes:GA_Text,GA_IntuiText,GA_LabelImage (IS)


These attributes tell the [frbuttonclass](../Libraries_Manual_guide/node0524.html) object what kind of imagery to use
as its display element.  See their description in the [gadgetclass](../Libraries_Manual_guide/node04F2.html) entry
for more information.
