# 33 / / Other Chunk Management Functions / EntryHandler()


This is used to install your own custom chunk entry handler.  See the
"[Custom Chunk Handlers](../Libraries_Manual_guide/node0457.html)" section below for more information.  [StopChunk()](../Libraries_Manual_guide/node0433.html),
[PropChunk()](../Libraries_Manual_guide/node0434.html), and [CollectionChunk()](../Libraries_Manual_guide/node0437.html) are internally built on top of this.
