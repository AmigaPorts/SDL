# B / propgclass / Attributes: PGA_Borderless (I)


This is a boolean attribute which corresponds to the [PROPBORDERLESS](../Libraries_Manual_guide/node0161.html#line19) flag of
the [PropInfo](../Libraries_Manual_guide/node0161.html) structure's [Flags](../Libraries_Manual_guide/node0161.html#line16) field (defined in <intuition/[intuition.h](../Includes_and_Autodocs_2._guide/node00D4.html#line498)>).
If this attribute is TRUE, the new [propgclass](../Libraries_Manual_guide/node0507.html) object will not have a
border around it.  In an [AUTOKNOB](../Libraries_Manual_guide/node0161.html#line23) propgclass gadget, if the [PROPNEWLOOK](../Libraries_Manual_guide/node0161.html#line32)
flag is set as well (see the [PGA_NewLook](../Libraries_Manual_guide/node050D.html) attribute), the knob will have a
3D appearance.
