# B / frameiclass / Changed Methods: IM_DRAWFRAME


This method is almost the same as the [frameiclass](../Libraries_Manual_guide/node04DF.html) [IM_DRAW](../Libraries_Manual_guide/node04E0.html) method, except
this method accepts a width and height that overrides the width and height
stored in the object's [Image](../Libraries_Manual_guide/node01BA.html) structure.  It uses the same drawing states
as the frameiclass's IM_DRAW method.  See the [imageclass](../Libraries_Manual_guide/node04D1.html) description for
[IM_DRAWFRAME](../Libraries_Manual_guide/node04D5.html) for more information.
