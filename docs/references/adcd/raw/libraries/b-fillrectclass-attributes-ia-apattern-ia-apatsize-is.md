# B / fillrectclass / Attributes: IA_APattern, IA_APatSize (IS)


These attributes supply the [fillrectclass](../Libraries_Manual_guide/node04EB.html) object with an area fill
pattern.  The IA_APattern attribute points to the area fill pattern for
the object.  The IA_APatSize attribute is the depth of the area fill
pattern.  These attribute values are similar to the parameters passed to
the SetAfPt() macro (defined in <graphics/[gfxmacros.h](../Includes_and_Autodocs_2._guide/node00B6.html#line30)>) and indirectly
correspond to fields in a [RastPort](../Libraries_Manual_guide/node034A.html) structure.  For more information on
these patterns, see the section on patterns in the "[Graphics Primitives](../Libraries_Manual_guide/node0352.html)"
chapter of the Amiga ROM Kernel Reference Manual: Libraries.
