# 11 Special Functions / Easy Memory Allocation and Deallocation


Intuition has a pair of routines that enable applications to make multiple
memory allocations which are easily deallocated with a single call.  The
Intuition routines for memory management are [AllocRemember()](../Libraries_Manual_guide/node01F8.html) and
[FreeRemember()](../Libraries_Manual_guide/node01F8.html#line29).  These routines rely upon the [Remember](../Libraries_Manual_guide/node01FA.html) structure to track
allocations.
