# B / propgclass / Attributes: PGA_NewLook (I)


This is a boolean attribute which corresponds to the [PROPNEWLOOK](../Libraries_Manual_guide/node0161.html#line32) flag
[PropInfo](../Libraries_Manual_guide/node0161.html) structure's [Flags](../Libraries_Manual_guide/node0161.html#line16) field (defined in <intuition/[intuition.h](../Includes_and_Autodocs_2._guide/node00D4.html#line448)>).  If
this attribute is TRUE, the new [propgclass](../Libraries_Manual_guide/node0507.html) object will use Release 2
imagery rather than the Release 1.3 imagery.
