# 5 / / Gadget Structure For String Gadgets / Imagery and Highlighting


Any type of image may be supplied for the rendering of a [string](../Libraries_Manual_guide/node0164.html)
gadget--image, border, or no image at all.  The highlighting for a string
gadget must be the complementing type ([GFLG_GADGHCOMP](../Libraries_Manual_guide/node014A.html#line8)).  Alternate imagery
may not be used for highlighting.
