# 4 / / The IDCMP And Gadgets / Application Gadgets


The application may place gadgets in windows to request various kinds of
input from the user.  These gadgets may be specified in the
[OpenWindowTagList()](../Libraries_Manual_guide/node0103.html) call, or they may be created and added to the window
later.  For details about creating and using gadgets, see the chapters on
"[Intuition Gadgets](../Libraries_Manual_guide/node012F.html)" and the "[GadTools Library](../Libraries_Manual_guide/node0258.html)".
