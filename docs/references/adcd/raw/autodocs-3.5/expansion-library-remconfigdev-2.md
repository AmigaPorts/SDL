# expansion.library/RemConfigDev



   NAME
	RemConfigDev - remove a [ConfigDev](../Includes_and_Autodocs_3._guide/node05F1.html#line31) structure from the system

   SYNOPSIS
	RemConfigDev( configDev )
	              A0

   FUNCTION
	(Not typically called by user code)

	This routine removes the specified [ConfigDev](../Includes_and_Autodocs_3._guide/node05F1.html#line31) structure from the
	list of Configuration Devices in the system.

   INPUTS
	configDev - a valid [ConfigDev](../Includes_and_Autodocs_3._guide/node05F1.html#line31) structure.
