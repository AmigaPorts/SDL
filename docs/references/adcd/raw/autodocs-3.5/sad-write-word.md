# SAD/WRITE_WORD



 WRITE WORD - [Write](../Includes_and_Autodocs_3._guide/node01D1.html) the given data to the address given

 Command:	$AF $02
 Data:		$ww $xx $yy $zz $qq $rr

 [Write](../Includes_and_Autodocs_3._guide/node01D1.html) the word <$qqrr> to address <$wwxxyyzz>

 Command will be ACK'ed when received.
 Command ACK:	$00 $02
 Command DONE:	$1F $02
